# Asset credits

All files in this folder come from the three.js examples (github.com/mrdoob/three.js, examples/).

| File | Source | Licence |
| --- | --- | --- |
| `player.json` | `examples/models/gltf/readyplayer.me.glb`, a Ready Player Me sample avatar | Ready Player Me terms; the game hides its suit jacket and hat and adds its own jersey, gear and kit colours |
| `moves.json` | `examples/models/gltf/Xbot.glb`, Mixamo character and animations (idle, walk, run) | Mixamo terms; only the motion data is used, retargeted onto `player.glb` |
| `grass.jpg` | `examples/textures/terrain/grasslight-big.jpg`, "Dark grass" from opengameart.org | CC BY 3.0 |

The two models are converted from .glb to glTF JSON with embedded data so the artifact host can serve them.

This build is a prototype. Check these licences again before any public or commercial release.
